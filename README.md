# PDF Form Stamper

PDF 및 이미지 서식 위에 텍스트, 체크표시, 서명을 배치하고 PDF 또는 JPG로 저장할 수 있는 브라우저 기반 서식 입력 도구입니다.

별도의 서버 설치 없이 HTML 파일 하나로 실행할 수 있으며, 보험청구서, 신청서, 동의서, 확인서 등 고정 양식 문서에 필요한 값을 빠르게 입력하는 용도로 사용할 수 있습니다.

## 주요 기능

### 1. PDF 및 이미지 서식 불러오기

- PDF 파일 불러오기
- PNG, JPG 이미지 파일 불러오기
- 드래그 앤 드롭 방식 파일 열기 지원
- 여러 페이지 PDF 렌더링 지원
- 모바일 화면에서는 PDF 페이지 크기를 자동 조정

### 2. 텍스트 입력 필드 배치

- PDF 또는 이미지 위 원하는 위치에 텍스트 필드 추가
- 필드별 라벨, 값, 페이지, X/Y 좌표, 글자 크기, 색상 설정
- 텍스트 길이에 따라 폭을 자동 조정하는 자동폭 기능
- 자동폭 해제 후 수동 폭 조절 가능
- 여러 줄 입력 지원
- 값 입력 탭에서 필드별 값을 빠르게 입력 가능

### 3. 체크표시 입력

- 체크 필드 추가
- 체크 기호 선택 지원
  - `✔`
  - `✓`
  - `●`
  - `○`
  - `■`
  - `□`
- 단독 체크 항목 및 그룹형 체크 항목 처리
- 체크박스 위치 미세 조정 가능

### 4. 서명 입력

- 마우스 또는 터치로 직접 서명 그리기
- PNG, JPG 등 이미지 서명 업로드
- 서명 필드 이동 및 크기 조절
- 기존 서명 복사 기능
- 서명 이미지는 비율을 유지한 상태로 영역 안에 맞춰 저장

### 5. 필드 편집 기능

- 필드 목록에서 전체 필드 확인
- 필드 선택 후 상세 편집 가능
- 페이지, 좌표, 글자 크기, 폭, 색상, 값 수정
- 선택 필드 복제
- 선택 필드 삭제
- 미니 이동 버튼으로 1px 단위 위치 조정
- 키보드 화살표 이동 지원
  - 화살표: 1px 이동
  - Shift + 화살표: 10px 이동

### 6. 미리보기 모드

- 포스트잇 배경, 테두리, 핸들바를 숨겨 저장 결과에 가깝게 확인
- 미리보기 상태에서도 필드 선택 및 이동 가능
- 빈 필드는 hover 시 점선 표시

### 7. 저장 및 내보내기

- 원본 PDF 위에 입력값을 합성하여 새 PDF 저장
- 이미지 서식을 PDF로 변환하여 저장
- PDF 또는 이미지 서식을 JPG로 저장
- 여러 페이지 PDF는 페이지별 JPG를 ZIP 파일로 저장
- 현재 보이는 페이지, 선택 필드가 있는 페이지, 특정 페이지, 전체 페이지 저장 지원
- JPG 저장 시 화면 표시용 저해상도 canvas가 아니라 고해상도 렌더링 canvas를 별도로 사용

### 8. JSON 저장 및 불러오기

- 필드 위치만 JSON으로 저장
- 필드 위치와 입력값을 함께 JSON으로 저장
- 저장한 JSON 파일 불러오기
- 브라우저 localStorage를 이용한 임시저장 지원
- 같은 양식을 반복 작성할 때 템플릿처럼 재사용 가능

### 9. 실행 취소 및 복원

- 실행 취소 버튼
- 다시 실행 버튼
- Ctrl + Z 실행 취소
- Ctrl + Y 또는 Ctrl + Shift + Z 다시 실행
- 필드 추가, 삭제, 이동, 크기 조절, JSON 불러오기, 자동감지 등 주요 변경사항 복원 지원

> 현재 일부 텍스트 입력 및 상세 편집 변경은 Undo/Redo 단위 처리 개선 여지가 있습니다.

## 사용 방법

### 1. 파일 열기

상단의 `파일 열기` 버튼을 누르거나 PDF/JPG/PNG 파일을 화면에 드래그 앤 드롭합니다.

지원 형식:

- PDF
- PNG
- JPG / JPEG

### 2. 텍스트 필드 추가

1. 상단의 `＋ 텍스트` 버튼을 클릭합니다.
2. 문서에서 값을 넣을 위치를 클릭합니다.
3. 왼쪽 `값 입력` 탭 또는 문서 위 필드에서 내용을 입력합니다.
4. 필요하면 `상세 편집` 탭에서 좌표, 글자 크기, 색상, 폭을 조정합니다.

### 3. 체크 필드 추가

1. 상단의 `＋ 체크` 버튼을 클릭합니다.
2. 체크박스 위치를 클릭합니다.
3. 왼쪽 입력 패널에서 체크 기호를 선택하거나 필드 위치를 조정합니다.

### 4. 서명 추가

1. 상단의 `✍ 서명` 버튼을 클릭합니다.
2. 직접 서명을 그리거나 서명 이미지를 업로드합니다.
3. 문서 위에 생성된 서명 필드를 원하는 위치로 이동합니다.
4. 크기 조절 핸들로 서명 크기를 조정합니다.

### 5. 저장

PDF로 저장하려면 `PDF 저장` 버튼을 누릅니다.

JPG로 저장하려면 저장 대상 페이지를 선택한 뒤 `JPG 저장` 버튼을 누릅니다.

저장 대상은 다음 중 선택할 수 있습니다.

- 현재쪽
- 선택쪽
- 특정 페이지
- 전체 ZIP

## JSON 템플릿 사용

반복해서 작성하는 서식은 JSON 템플릿으로 저장할 수 있습니다.

### 위치만 저장

`저장` 탭에서 `위치만 저장`을 선택하면 필드 위치와 설정만 저장됩니다. 입력값은 제외됩니다.

반복 서식의 기본 템플릿으로 사용하기 적합합니다.

### 위치 + 값 저장

`위치+값 저장`을 선택하면 필드 위치와 입력값이 함께 저장됩니다.

작성 중인 문서를 나중에 이어서 작업할 때 적합합니다.

### 불러오기

저장한 JSON 파일을 선택하면 다음 방식으로 불러올 수 있습니다.

- 위치만 적용
- 위치 + 값 적용

## 브라우저 임시저장

`브라우저 임시저장` 기능은 현재 브라우저의 localStorage에 작업 내용을 저장합니다.

단, 서명 이미지가 많거나 파일 크기가 큰 경우 브라우저 저장 용량 제한에 걸릴 수 있습니다. 중요한 작업은 JSON 파일로 별도 저장하는 것이 안전합니다.

## 외부 라이브러리 및 CDN 의존성

현재 버전은 별도의 빌드 과정 없이 단일 HTML 파일에서 외부 CDN 라이브러리를 직접 불러와 실행합니다.

사용 중인 주요 외부 라이브러리는 다음과 같습니다.

| 라이브러리 | 용도 |
|---|---|
| PDF.js | 브라우저에서 PDF 파일을 읽고 각 페이지를 canvas로 렌더링 |
| pdf-lib | 원본 PDF 위에 텍스트, 체크표시, 서명 이미지를 합성하여 새 PDF 생성 |
| fontkit | pdf-lib에서 외부 한글 폰트를 PDF에 임베드하기 위해 사용 |
| JSZip | 여러 페이지를 JPG로 저장할 때 ZIP 파일로 묶어 다운로드 |
| Google Fonts / Nanum Gothic | 화면 표시용 한글 웹폰트 |
| Noto Sans CJK KR | PDF 저장 시 한글 텍스트 출력을 위한 임베드 폰트 |

현재 `index.html`에서는 다음 CDN 리소스를 사용합니다.

```html
<script src="https://unpkg.com/pdf-lib@1.17.1/dist/pdf-lib.min.js"></script>
<script src="https://unpkg.com/@pdf-lib/fontkit@1.1.1/dist/fontkit.umd.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js"></script>
